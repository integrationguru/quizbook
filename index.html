Look inside

How every book is laid out

Three things shape the format: a question you can drill without seeing the answer, an index that lets you revise backwards from the answers, and a way to browse by feature type when you want to hammer one topic. Every book is built the same way — one shown here from each of the three Bees.

The question cardClues run obscure to obvious, each tagged by feature type and marked in the text. Geography Bee.

Clue referenceEvery clue grouped by type, linked to each question that uses it. History Bee.

Answers indexEvery answer alphabetically, so you can revise backwards. Science Bee.

Pages from the Geography, History and Science Bee complete editions.

Study guides

The facts the questions are built from

Geography, History and Science each come with a study guide drawn from the same material as the questions — the places, people and events the clues point at, written to read straight through rather than to be quizzed on. The highlighted phrase in each entry is the giveaway: the line that, on its own, should be enough to buzz.

GeographyGrouped by feature — cities, rivers, ranges — each entry carrying the detail a clue is most likely to hang on.

HistoryOrdered by era and then by country, with the rulers, events and places that come up under each.

ScienceGrouped by topic, so a run of questions on one subject can be revised in one sitting.
